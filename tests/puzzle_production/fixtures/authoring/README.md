# Künstliche ZA-1-Pakete

Vier mit `tools.puzzle_production.za1_fixtures.make` erzeugte kleine technische
Pakete: Direktimport/Reparatur × Mono/Farbe, 6×4 und 4×6. Reparaturen enthalten
eine echte ausgewählte Änderung samt vollständigem Verlauf. Sämtliche Freigaben
sind **test-only**, keine Eigentümererklärungen. Endfreigaben entstehen ausschließlich
im temporären Replay. Keine Katalogaufnahme.

Neue Rätsel erweitern diese technischen Fixtures nicht. Der frühere reale
Knoblauch-Referenztest samt doppeltem Test-ZIP wurde entfernt; sein gebundener
historischer Nachweis steht in der [Nachweiszuordnung](https://github.com/venomenon328/picross/blob/6fe91a08a4d073547df43c6aebbe8ead4c45ae0f/docs/ZA1_VERIFICATION.md).
