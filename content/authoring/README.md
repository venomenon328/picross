# Aktuelle Produktionsarbeit

Neue Jobs verwenden genau einen aktuellen Record unter
`<puzzle_id>/current/record.json` mit Verweisen auf aktuell benötigte Originale im Arbeitsrelease.
Der gemeinsame `index.json` enthält ausschließlich Verweise auf die Records.
Ansichten und Folgeaufträge werden daraus abgeleitet.

[Authoring](../../docs/production/authoring/PUZZLE_AUTHORING.md) beschreibt die
fünf Phasen und Entscheidungen; [PW-B](../../docs/tools/PW_B_CONTRACT.md) die
geschlossene technische Form, sichere Publikation und Wiederaufnahme.

Angebote bis zur tatsächlichen Wahl erhalten. Ausgeschiedene/ersetzte Varianten
und ausschließlich zugehörige Dateien danach ohne Archivierung entfernen.
Kein Prompt-, Generator-, Reparatur- oder Korrekturarchiv; keine ZIP-, Handoff-,
Inventar- oder Regelbuchkopie als Voraussetzung. Aktueller Proof, echte Rechte,
Sichturteile und tatsächliche Entscheidungen bleiben erforderlich.

Der Arbeitsref sichert aktuelle Angebote. Integration erfolgt auf einem sauberen
Branch vom aktuellen Main mit ausschließlich gewählten finalen Produktdaten.
Completion und Retirement verlangen keinen vorherigen Mainimport von Arbeitsdateien.
Unbekannte, fremde oder noch offene Arbeit bleibt geschützt.
